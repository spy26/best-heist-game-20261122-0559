Gilded Vault — The Sun Opal Heist: a complete top-down stealth heist game that runs offline in a desktop browser from static files. One grand gallery, three patrolling guards with vision cones, two sweeping wall cameras, a glass vault case holding the Sun Opal, three side-loot pieces, and a live alarm meter — all visible in one frame. Three routes to the jewel (the exposed red carpet, the west gallery, the locked east service gate), three tools at a cost (coin toss to lure guards, smoke bomb to blind cones, lockpick to open the vault silently — or smash the glass and pay +35 alarm), and a clean getaway that pays off the planning with time and ghost bonuses.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

WASD / arrows or click to move, Shift to dash, E (hold) to pick locks, F to smash the vault glass, right-click / C to toss a coin, Q for a smoke bomb, P to pause. Steal the Sun Opal, then reach the green EXIT before the alarm hits 100%.
